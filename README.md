# کمپین بازاریابی به‌شور

سیستم مدیریت کمپین تبلیغاتی حضوری برند [به‌شور](https://github.com/MHBehzadian/behshoor-olive) در زنجان: ثبت آدرس مغازه‌ها از طریق بات تلگرام، و مدیریت پخش پک/پیگیری سفارش/تحویل/سرکشی و حساب کمیسیون از طریق یک وب‌اپ با نقشه.

منطق کامل کسب‌وکار (نقش‌ها، چرخه‌ی روزها، حساب و کمیسیون): [آرتیفکت کامل](https://claude.ai/code/artifact/54c6e469-ffc4-436e-9875-e0dc2c5fb09e)

## نصب (روی یک سرور اوبونتو/دبیان تازه)

```bash
curl -fsSL https://raw.githubusercontent.com/MHBehzadian/behshoor-campaign/main/install.sh | bash
```

قبلش دامنه‌ای که می‌خوای (پیش‌فرض `campaign.behshoor-olive.ir`) رو با یه رکورد A به IP همین سرور وصل کن — بدون این، گرفتن گواهی SSL شکست می‌خوره (خودش دوباره تلاش می‌کنه، ولی سایت تا وصل شدن DNS بالا نمیاد).

نصب‌کننده به‌صورت تعاملی می‌پرسه: دامنه، توکن بات تلگرام (از @BotFather)، آیدی عددی تلگرامت (برای دریافت بکاپ‌ها، از @userinfobot بگیر)، و نام‌کاربری/رمز ادمین وب‌سایت. بقیه (رمز دیتابیس، کلید امنیتی، دیپلوی، مایگریشن، ساخت ادمین، کرون بکاپ) خودکاره. اجرای دوباره‌ش هم امنه — فقط تنظیماتی که هنوز نداری رو می‌پرسه.

بعد از تموم شدن: `https://<دامنه>` بالاست (چند دقیقه‌ای طول می‌کشه تا SSL بگیره).

## بکاپ و بازیابی

هر ۶ ساعت یه بکاپ کامل از دیتابیس گرفته می‌شه و از طریق همون بات تلگرام برات (به همون آیدی عددی که موقع نصب دادی) فرستاده می‌شه — یعنی همیشه یه نسخه‌ی تازه دستته، حتی روی گوشیت.

اگه یه وقت مشکلی پیش اومد و خواستی همه‌چی رو به یه بکاپ برگردونی:

```bash
cd /opt/behshoor-campaign
./scripts/restore.sh <فایل-بکاپ>.sql.gz
```

## ساختار پروژه

- `backend/` — بات تلگرام در‌آور (aiogram) + API وب‌اپ (FastAPI) + دیتابیس (SQLAlchemy/Alembic/PostgreSQL)
- `webapp/` — پنل ادمین + صفحه‌ی ویزیتور + صفحه‌ی پخش (HTML/CSS/JS خام با نقشه‌ی Leaflet/OpenStreetMap، بدون نیاز به Node/بیلد)
- `deploy/Caddyfile` — پروکسی + SSL خودکار
- `scripts/` — بکاپ، بازیابی، ساخت ادمین اول، دیتای تستی
- `docker-compose.yml` — کل استک (دیتابیس، بک‌اند، بات، Caddy)

جزئیات فنی هر فاز و دستور اجرای محلی (بدون Docker) توی [PROGRESS.md](PROGRESS.md) و [CLAUDE.md](CLAUDE.md) هست.
